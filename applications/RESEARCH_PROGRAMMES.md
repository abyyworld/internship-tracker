# Funded research programmes — a list to check, not a list to trust

22 programmes that survived verification, nearly all of them a
direct robotics fit, and **not one carries a date I was able to confirm.**

That is a statement about where this was compiled, not about the
programmes. The twenty researchers that assembled it ran inside a build
container whose network policy refuses university domains — `ethz.ch`,
`kaust.edu.sa`, `is.mpg.de` and the rest all answered `403 CONNECT` — and
the search budget ran out partway through. So every date below is either
last year's round rolled forward or an inference, and each row says which.

None of it is in the tracker. `data/research_programmes.json` refuses any
entry without a deadline, deliberately: a programme listed with a projected
date reads as covered while leaving you to find out for yourself when it
really closes, which is how Mitacs was missed by five days. A list that
admits it is unchecked beats a tracker that lies quietly.

**What to do with it.** Open each link, find the real date, put it in
`data/research_programmes.json`. The tracker reads it from there and the
Closing filter starts working. About a minute each — start at the top,
which is sorted by how soon the window is thought to open.
