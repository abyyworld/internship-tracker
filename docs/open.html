Your CV helper isn’t running

The editor runs entirely on this machine — that is how your CV, your fact bank and your API key stay off the internet. Nothing is listening on 127.0.0.1:8765 right now, so there is nothing to open.

  1. Open the project folder — Desktop → other projects → internship watcher.
  2. Double-click install-login-service.command. It installs the helper so macOS starts it at every login and restarts it if it stops: no window to keep open.
  3. Come back here and press Try again.

Haven’t got that file? Download it from GitHub, then in Finder right-click it → Open (macOS warns about downloaded scripts once). It finds the project folder by itself. start-autoapply.command starts the helper just for the current session instead.
