Where things go

Your CV, the advert and your key are kept in this browser’s own storage, on this device. When you press Rewrite, this page sends the CV text and the advert directly to the provider above using your key — the same call the local helper would make. It never passes through GitHub or any server of this project.

Google AI Studio is the free tier and is known to accept requests from a web page. Some providers refuse browser requests on purpose; if yours does, the message below will say exactly that, and the local helper is the way round it.
